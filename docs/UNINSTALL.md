# Uninstall

Use Windows **Installed apps** to uninstall Dimensions Auto Evaluate.

Uninstall removes application binaries and shortcuts. It intentionally preserves `%LOCALAPPDATA%\DimensionsAutoEvaluate` and provider credentials.

To remove all data manually after uninstall, delete that directory and remove `DimensionsAutoEvaluate/*` entries from Windows Credential Manager. This is irreversible.
