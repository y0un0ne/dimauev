# Troubleshooting

## App does not open

Check `%LOCALAPPDATA%\DimensionsAutoEvaluate\logs`. On managed laptops, ask IT whether the executable was blocked.

## Extract browser does not continue

Navigate manually to Guardrail Identify, wait for the filter UI, then click **Continue after login**.

## Evaluator appears slow

Overview shows current provider/account and timeout. A hanging provider request falls back after the configured timeout.

## Excel report is locked

Close Excel to replace the canonical workbook, or use the generated timestamped copy.

## Support bundle

Share logs and status JSON only after checking organizational privacy policy. Never share browser profile or extracted conversations casually.
