# First Run

1. Launch the app. Your default browser opens the local dashboard.
2. Open **Settings** and add at least one Gemini account API key.
3. Open **Extract** and select a date.
4. The bundled Playwright Chromium opens Dimensions.
5. Log in manually and navigate to `Sahabat Chat -> Conversation Verify -> Guardrail Identify`.
6. Return to Overview and click **Continue after login**.
7. Review the cloud-processing disclosure and run **Evaluate** after extraction data exists.
8. Run **Reports** after evaluator results exist.

Credentials for AI providers are stored in Windows Credential Manager. The app does not separately collect your Dimensions password, but authenticated cookies and session state persist in the local browser profile.
