# Install Dimensions Auto Evaluate

## Supported systems

- Windows 10 or Windows 11, x64
- Standard Windows user account
- No Python, Node.js, npm, Git, or separate browser installation required
- Internet access is still required for Dimensions and configured AI providers

## Install

1. Download `DimensionsAutoEvaluate-Setup-<version>-win-x64.exe` from the release page.
2. Run the installer.
3. Choose whether to create a desktop shortcut.
4. Launch **Dimensions Auto Evaluate** from Start Menu or desktop.

The app installs per user under `%LOCALAPPDATA%\Programs\DimensionsAutoEvaluate` and does not request administrator rights.

## Windows warnings

Unsigned builds can trigger SmartScreen or corporate endpoint controls. Verify the published SHA-256 checksum. Do not bypass company policy; ask IT to approve the application when required.

## Local data

Application data is stored under `%LOCALAPPDATA%\DimensionsAutoEvaluate`. Installer upgrades preserve this directory.
